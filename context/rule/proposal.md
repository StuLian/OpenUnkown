# 变更提案模板（写前确认单）

> 用法：写代码 agent 在动手实现**之前**填写本模板并停下等人确认。
> 获批前不得写任何产品代码。
> 轻量变更（注释/文案/typo/单文件 <20 行且不动逻辑）免填，直接改 + 写 feature.md。
